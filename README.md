# 游戏王工具箱

当前仓库处于初始化阶段，仅包含项目管理文件，尚未加入应用源码、依赖清单或可运行程序。

## 仓库文件

- [AGENTS.md](AGENTS.md)：项目协作要求、提交审核、推送授权、历史隐私检查及文档维护规则。
- [.gitignore](.gitignore)：依赖、缓存、构建产物、凭据和本地个人数据的基础排除规则；排除不会删除本地文件。

## 安装与启动

目前没有可执行的安装或启动步骤。加入应用源码后，应根据实际技术栈和验证结果补充环境要求、安装、启动、配置及使用说明。

## 版本管理

每项完整修改通过相关检查后创建本地提交，只纳入本次已审核的内容。推送需要用户单独授权，并审核将上传的全部提交及其历史内容。

源码、运行必需资源、配置模板和依赖锁定文件应纳入版本管理；真实凭据和个人数据留在本地。基础忽略规则需要在引入实际文件后复核，具体要求见 [AGENTS.md](AGENTS.md)。
