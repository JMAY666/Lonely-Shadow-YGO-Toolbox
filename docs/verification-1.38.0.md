# 1.38.0 情报站验证记录

本次新增本地情报站，包含可复用的通用终场标注、手坑用途 TAG／单层文件夹和手动断点资料。使用、数据结构边界和恢复方式见[情报站说明](intelligence.md)。

## 数据与兼容

- 新资料扩展现有 `tag-library.json`，手坑成员与用途 TAG 采用同一份资料和一次原子提交，沿用已有修订备份。旧版文件首次写入前备份；重复添加／导入以稳定卡号和来源键去重。
- 通用终场标注不参与路线评价，只在用户明确应用时复制到当前实例的原有 `annotations` 格式。修改、删除通用标注和读取／导入历史来源时，合成历史方案文件逐字节保持一致。
- 卡库缺卡保留编号、备注、效果快照和断点引用；过期修订和写入失败拒绝提交，编辑输入保留。冲突可读取新版并核对后保留输入继续编辑。
- 新用途 TAG 不进入现有卡组、方案的主／副系列自动识别。TAG 管理和情报站共用新增成员的主卡组类型校验。

测试证明资料管理、同步和复用行为，不证明示例卡牌搭配的规则合法性或战略效果。断点始终是用户手动维护的资料；没有测试或宣称实时对局识别、自动干扰、社区发布能力。本次没有重新进行真人联机或外部客户端内存读取验收。
