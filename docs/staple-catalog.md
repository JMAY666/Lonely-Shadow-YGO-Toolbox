# 常用手坑与解场资料

核对日期：2026-09-20。范围为跨 OCG／Master Duel 的常见与环境针对性选择，不是即时使用率排名，也不是任何单一环境的禁限卡表。64 张不同卡牌形成 28 份手坑资料与 39 份解场资料；无限泡影、命王的螺旋、霆王的闪光在两类中分别维护。

## 联网依据

- [KONAMI 官方卡牌数据库](https://www.db.yugioh-card.com/yugiohdb/card_search.action?request_locale=ja)：逐卡读取日文官方效果，核对发动时点、费用、处理方式及限制。每张卡的具体官方链接保存在资料来源中。
- [YGOPRODeck API](https://ygoprodeck.com/api-guide/)：用卡号、英文名和官方数据库编号交叉核对，通用卡候选参考其 staple 标记。该标记包含历史及受禁限的卡，不能直接当作当前合法性名单。
- [Road of the King：OCG 2026.07 #8、#9](https://roadoftheking.com/ocg-2026-07-metagame-report-8-9/)：报告覆盖 2026-08-22 至 2026-08-30 的 21 场比赛、103 份上位构筑；正文明确讨论幽鬼兔与原始生命态 尼比鲁的环境针对性。它支持针对性选择的背景，不足以断言本文全部卡牌的即时使用排名。
- [Master Duel Top Cards](https://www.masterduelmeta.com/top-cards)：已读取页面，页面标示更新于 2026-09-05。此次未提取经验证的逐卡使用率，所以资料不附使用率或胜率数字。

卡名与效果编辑所用中文文本采用已安装卡库，同一卡号附上英文名与官方页面编号。人工备注为效果摘要及使用条件，不修改卡牌原文，不保证具体场面的规则合法性。没有借用其他玩家的构筑或账号数据。

## 分类规则

每份资料只有一个主要文件夹，多用途通过「效果 · …」TAG 交叉筛选。手坑的墓地除外和场上除外区分记录；效果无效、发动无效、发动限制、破坏、送墓、回手及对玩家处理分别注明。

幽鬼兔是破坏而非无效，灰流丽无效效果，屋敷童无效发动。原始生命态 尼比鲁通过发动效果解放，坏兽通过召唤手续解放，二者对抗性和无效的适用方式不同。欢聚友伴按特召来源分别归类，并保留空场要求及结束阶段洗回条件。列王系列手发陷阱逐张注明整局属性限制。额外卡组的解场手段只归入解场，不写入手坑成员。

效果匹配采用已核对的文本快照。完整文本相同而位置改变时可对应；文本不同或无法唯一匹配时保留旧效果和备注为待核对，不能仅用数字序号覆盖。

## 导入与维护

界面：情报站 → 手坑标记／解场标记 → 导入常用分类。操作同时合并两类资料，所有变更与用途 TAG 在一次原子保存中提交，保存前保留旧文件备份。既有非空用途、条件、文件夹和终场标注保留，新增效果备注独立合并；原整理说明始终可在参考资料中查看。

相同资料版本再次导入不重复写入，不恢复后来手动移除的备注或效果。删除整份资料后可再次导入。缺卡会列出并跳过，安装卡库后重试可补入这些卡。因文本变化而待核对的效果不自动计入已选择效果。

维护命令只针对已关闭的应用实例；脚本默认预检，显式 `--apply` 才写入。脚本获得与桌面服务相同的独占锁，避免运行中的应用并发修改。

```powershell
python scripts/import_staples.py --runtime "<个人运行目录>/runtime"
python scripts/import_staples.py --runtime "<个人运行目录>/runtime" --apply
```

公开资料文件为 `src/trainer/staples.json` 与 `src/trainer/staples-texts.json`。资料来源版本、说明和效果备注保存在个人 TAG 库的情报站记录中；备份位置沿用 `runtime/_trainer/backups/tags/<修订号>.json`。不要通过旧版本程序编辑新增的解场资料。效果 TAG 不参与系列自动识别，避免将解场用途误识别成卡组主题。
