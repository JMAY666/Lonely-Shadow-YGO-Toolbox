# 后攻条件化交康提示（1.30.0 / P1.2）

本期在[后攻局面记录](bo1-second.md)上增加有限案例的条件化比较。原始起手、观察日志和正式方案保持原归属。没有完整重建外部引擎局面，也没有后攻路线或斩杀规划；后续顺序见[执行文档](bo1-second-execution.md)。

## 支持范围

确定的条件建议只覆盖工具箱固定本地规则资源、对手第 1 回合主要阶段 1、所选效果为连锁 1 且当前最后连锁也是 1 的场景。输入必须来自玩家当前可知信息，并且仍在人工确认的响应窗口内。

| 公开动作 | 对比的手牌响应 |
| --- | --- |
| 阿鲁伯①检索烙印魔法／陷阱 | 灰流丽、无限泡影、幽鬼兔与不响应 |
| 莫邪①生成相剑衍生物 | 同上；灰流丽不因卡文另有抽牌效果就能响应① |
| 烙印融合的卡片发动 | 同上；不把融合后新怪兽出现的响应窗口混入魔法发动窗口 |

当前只识别经过核对的标准卡号：14558127、10045474、59438930、62962630、20001443、44362883。其他效果、卡号变体、其他阶段、多重连锁、额外保护或持续限制缺少完整案例时显示信息不足；不表示这些场景规则上无解。幽鬼兔本期仅比较手牌发动，无限泡影仅比较空场时从手牌发动。

MD、YGOPro、YGOPRO2、MDPRO3 外部记录只能显示本地案例参考，主要建议保持“信息不足”，不能标为内置规则实战。MD 卡池、禁限表和具体平台交互尚未逐项验收；不因本地核心通过就解除这个限制。

## 使用流程

1. 先按实际情况记录当前手牌及对手公开卡片、位置与表示。原始起手不会被这些记录覆盖。
2. 展开“核对次数和后攻保留用途”。按具体效果填写未用／已用／未知，为手牌标明无必须保留用途、必须保留作起动／素材／费用，或未核对。必须保留时填写具体用途。
3. 在原“核对当前局面”保存回合、阶段和公开资源。未结构化的旧次数／限制备注仍会阻止确定建议；先核对、转换或按真实依据更正，不能直接从文字推测。
4. 展开“填写结构化响应窗口”，选择准确来源实例和具体效果，填写连锁、速度、保护、其他公开影响、送墓替代及比较目标。保护属性可多选；空选项不自动代表已经核实没有保护。
5. 确认对手确实已发动、当前仍等待我方响应，再点击“生成／刷新提示”。默认最多显示三类响应，原因和证据按需展开。
6. “记录计划使用／保留”只记录玩家决定，不扣牌、不推进实际对局、不操作外部客户端。实际发动、费用移动和最终结果分别记录。

首次生成会核对当前引擎、完整 Lua 脚本集合、规则数据库及相关冻结卡文；资源身份不符时降为信息不足。后续同一资源身份复用核对结果。生成提示不延长窗口有效期。

## 建议与信息边界

- 同时显示所列规则条件、有限本地案例结果和策略倾向，不标“本局引擎验证通过”。
- 在阿鲁伯窗口有满足条件的泡影时，可建议泡影处理当前检索并保留灰流丽应对其他效果类型。只有灰流丽而后续未知时，综合比较会保留交与不交的取舍，不固定为见检索就交灰。选择“优先阻止当前处理”等目标会改变这个取舍。
- 幽鬼兔破坏阿鲁伯不阻止其检索；破坏莫邪后衍生物仍生成，但本地案例不能立即沿原莫邪＋衍生物同调召唤赤霄。对手还有其他怪兽时，不推断其已失去其他同调路线。破坏与无效分别记录。
- 实际交换、基准案例预计投入／移除、预计阻止的加牌分开显示。融合和素材处理不强行折算成卡差；不把“阻止获得”再算作实际移除。
- 同名副本和共享次数按同一组核对，不累加为独立阻抗。保留用途明确标为玩家核对；具体后攻路线及墓地／除外再利用仍未验证。
- 只给候选卡组或轴，不凭一张公开卡锁定完整构筑。未知手牌、盖卡、牌序和补点保持未知；案例假设双方不追加其他响应，不能当作实战事实。
- 来源、数据或规则缺失时显示缺项；当下未覆盖其他响应，不能宣称绝对最优、必胜、胜率或规则上无解。

## 实际发动与结果

“记录本次实际发动与次数”会给这次发动独立身份。尚未处理时先记录“已发动，尚未处理”；之后用“关联并补充处理结果”选择对应发动，不能新建另一条发动来冒充旧结果。

结果区分已结算、已结算但未适用、发动被无效和效果被无效。灰流丽／幽鬼兔按使用次数计数，发动被无效也不会返还使用次数；烙印融合按发动次数计数，发动无效与效果无效分别处理；阿鲁伯①②共用一次二选一，莫邪①②分别计数。无法套用这些已登记限制的其他效果继续作为人工备注，不推断。

补录较早动作不会清除较新动作或人工更正的次数；跨回合补录只保留历史，不覆盖当前回合。更正已确定结果、将已用次数改成未用时必须说明依据。以上仍是玩家确认的记录，不是自动识别的真实出牌。

## 保存和有效性

提示、生成时的已知局面和计划选择保存在本局私有记录的 `advice_history`，独立于实际观察 `events`。旧 P1.1 文件按需增加字段，查看历史不改写文件；原始起手和正式方案不变。

提示绑定局次、观察版本、响应窗口、知识版本和规则资源身份。窗口超过 30 秒、实际资源／次数更新、换局、断流或资源变化后，旧提示不能采用。复盘只展示生成时的比较和当时计划，实际结果在观察历史中查看；后来获知的信息不回填旧建议。
