# 1.50.0 复杂效果结构与查询适配验收

日期：2026-09-27。用户要求拓展卡片标注对原来无法表达／匹配的效果的支持。本次为模型、检索、详情和跨模块投影扩展，未恢复封存的AI学习计划。

## 实际变更

- 同一原卡文段可以包含多个真实效果单元；规则、永续、诱发及不同区域效果分别保存类别、条件、费用、对象和次数。父段保留原键与卡文指纹，不编造卡文编号，也不伪造获赋关系。
- 选择项可以各有发动区域、类别和对象要求，选择规则和共享次数明确展示；默认条件查询不能跨单元拼接。显式整卡范围才可跨单元。
- 新增无新连锁的延迟处理边界：本次发动预约、后续指定时点处理，后续不能借用当前费用或次数。详情、命中依据和能力快照均保留延迟关系；不增加规则引擎的实时调度或合法性推断。
- 动态追加超量素材怪兽的属性集合、战斗伤害承受者转移及卡组置顶／置底的数量区间得到明确表达和校验。
- 用途推导逐单元进行，个人新增段级标签不冒充具体子效果的依据；个人删除标签可屏蔽各子单元。备注仍按原段和卡文版本保留，历史能力快照不回填。

定义及正反例见[体系规范](card-annotation-system.md)，接纳清单和验收用例见[本轮清单](card-annotation-batch-2026-09-27-model-expansion.json)。
