合成内存测试覆盖先／后攻、重复起手、未知构建与依赖指纹、房间旧字段、尚未处理的开局消息、服务器数量不符、错过开局、非法列表容量、前后快照变化、观战／录像／换副／双打／交换视角，以及明确拒绝编辑器读取。对方卡牌对象设置不可读取的牌号地址，验证采样不解引用对方卡号。编排测试另覆盖新开局消息使旧工作区失效。

两个平台分别运行桌面智能识别用例，检查平台选择保留、YGOPRO2 不显示卡组识别入口、取消和迟到响应、自动下一局、输入冻结、匹配和计算调用、已选方案保持、后攻与漏发牌提示。模拟不替代真实联调，也不扩大真实后攻／重启验证范围。所有验收实例使用后台窗口和隔离数据，不移动系统鼠标或发送全局按键。

截图审查发现第二个平台的背景被原有 `nth-child(2)` 自动模式样式覆盖，已修正平台专用选择器的优先级。按用户补充要求，两个通用图案随后替换为客户端实际图标的同色系组合。新增品牌专项检查 900／1280／1600 宽度下的背景来源、离线 SVG 解码和两张平台卡片的方形尺寸；最终重新打包并复验两个平台的智能识别界面，均通过。完整基线运行期间补充的图标和样式修改由最终包专项覆盖，不把先前临时包的截图作为最终图标验收。
