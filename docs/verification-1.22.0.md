# 1.22.0 验收记录

## 验证范围

- 合成状态测试覆盖旧值隔离、猜拳／选择阶段、先后攻、不同对局 ID、断开恢复、手动更正、过期确认和记录写入失败。
- 真实 YGOPro 主动先攻三轮：全部在正式开局后识别为先攻，每轮先观察到我方选择窗口，等待阶段不提前输出旧结果。
- 主动后攻三轮：全部识别为后攻；第 1 回合及第 2 回合保持后攻身份，不把当前行动回合当作先后攻。
- 猜拳输掉、由对手决定一轮：未观察到我方选择窗口，最终识别为我方后攻。七次独立开局均有不同的局次 ID。
- 真实界面点击确认后进入下一步；将自动后攻手动更正为先攻后确认，落盘中保留原自动判断和人工选择，再恢复自动结果成功。
- 桌面验收使用后台 Electron 与独立数据目录；游戏输入均由用户执行。个人对局日志、进程信息和截图仅保留在 `.local/ygopro-order-live-*`。

## 复测入口

`desktop/ygopro-order-live.cjs` 启动隔离的后台验收实例，`YGO_TEST_RUN` 区分目录，`YGO_ORDER_LIVE_DECK` 指向本地验收卡组 JSON。跳过已单独验证的卡组交互，从预览点击开始决斗；真实先后攻接口不替换为测试响应。游戏开始、猜拳和选择始终由用户操作。

该实例将变化写入 `evidence/observations.jsonl`，最新状态在 `evidence/latest.json`；`control.json` 可请求隔离工具箱确认、返回或关闭，不向 YGOPro 发送操作。正式识别依据和内存位置见 [对局读取路径](ygopro-live-state-research.md)。

## 功能边界

已适配构建的普通玩家对局采用最终开局数据判断，不根据猜拳输赢或手牌数量猜测。观战、录像、TAG 和单人谜题不支持。自动起手与展开、后攻展开尚未接入；当前确认后保留结果并进入下一阶段说明页。
