# 持续适用的规则与模拟状态

以「点唱机酒吧“杀手级调整曲”」为例：①在场地区表侧存在时适用，不入连锁，允许主要阶段额外召唤 1 只调整。同类额外召唤机会不能反复叠加；③结算后施加的调整特召限制持续至回合结束。[KONAMI 官方 FAQ](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=21962&ope=4&request_locale=ja)

当前卡片脚本将①注册为场地区的 `EFFECT_EXTRA_SUMMON_COUNT`，目标限调整；③则向玩家注册持续至回合结束的 `EFFECT_CANNOT_SPECIAL_SUMMON`。因此，失去场地会失去尚未使用的①许可，但已经用过的额外机会不会因重新放置场地而恢复，③的限制也不会仅因场地离场而消失。

## 实际模拟方式

`TrainingModular` 在隔离规则核心中重放原始调用与后续决策，或继续同一有效前缀的隔离核心。场地／永续效果、无效状态、目标范围、次数限制及玩家身上的后续限制都由该核心维护。可选动作来自当前引擎决策窗口，每个输入继续经过规则验证，不从牌名或场上卡数推测合法性。

局面摘要不是完整可执行的规则状态，不能仅凭相同手牌和场面判定两个局面等价。1.28.3 的模块状态补充以下引擎数据，随模拟结果、已确认前缀和状态比较一起保留：

- `normal_summons_used`：已使用的普通通常召唤次数，沿用原字段。
- `normal_summon_limit`：规则核心当前计算的普通通常召唤上限。
- `extra_normal_summon_used`：该玩家本回合是否已经使用“通常召唤外再召唤”的机会。
- `effect_usage`：沿用引擎已记录的效果次数数据。

额外机会“未使用”不等于当前一定能召唤：还需存在有效的许可，且怪兽类型、区域、召唤条件与限制都满足。旧来源没有这些新增字段时仍保留原文件，以当前完整引擎重放判断，不补造历史权限。

## 实测范围

`npm run test:modular -- --suite=rules` 和对应发布包套件覆盖：

1. 普通召唤用完后，场地允许再召唤调整，不允许非调整；额外机会用完后拒绝第三次召唤。
2. 隔离搜索能重放两次召唤，保留两类次数，真实验收实例的状态不变。
3. 额外召唤之前移除场地，许可消失；已经用过后换同名场地，机会不恢复。
4. ③处理后及场地离场后，隔离「死者苏生」的选卡窗口仍拒绝非调整，只提供当前合法目标。

这验证了该场地的额外召唤和后续限制，以及实际重放的保留方式；其他场地／永续卡仍按各自脚本和规则核心处理，不宣称已逐卡穷举验收。
