# 1.39.0 常用手坑与解场分类

增加独立解场资料库、分类文件夹和专用用途 TAG。内置联网核对的常用卡资料，支持显式导入、原子保存、原文件备份、保留已有备注，以及同版本重复导入不再写入。

资料共 64 张不同卡牌，形成 28 份手坑资料与 39 份解场资料；三张卡同时收录在两个资料区，分别编辑。卡片来源、核对日期、用途说明和效果区别见[资料目录](staple-catalog.md)。
