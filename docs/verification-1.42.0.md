# 1.42.0 知识包验收记录

日期：2026-09-23。范围为知识包制作/安装生命周期及原生决策资料的受限规则验证和消费适配；不恢复封存的 AI 学习计划，不训练模型。

## 验收口径

- 模式与存储测试使用独立临时目录，覆盖来源失效、共享依赖、同版冲突、原子失败、三方合并、历史保留和索引复用。
- 队列测试使用明确标注的合成回调检查取消/恢复、迟到结果、磁盘失败、缓存和输入变化；这些测试不能冒充真实规则引擎验证。
- 桌面测试使用隐藏 Electron、隔离数据和应用内部输入/截图接口；不移动系统鼠标、不发送全局按键。
- 原生专项通过真实引擎录制普通召唤来源，验证导入、固定起手、预算限制、本机检查、结果复用、计算许可、展开匹配、模块化输出及版本固定。测试牌表使用自由练习规则，不能作为赛事合法构筑。
- 公开烙印示例用于验证内容关系与制作/安装流程，仍保留未逐条引擎验证状态，不与合成原生验收混为一谈。
