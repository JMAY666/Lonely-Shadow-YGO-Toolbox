# 后攻起手分析

1.42.1 新增独立的本地起手资源分析。入口为「决斗 → BO1 → 手动选择 → 卡组 → 后手」及自动识别的后攻冻结起手；资料维护入口为「情报站 → 起手分析」。

## 使用

手动选择完整起手后点击「分析后攻起手」。自动识别仍沿用已有客户端开局适配：确认后攻并冻结完整起手后，智能识别进入同一分析页；逐步识别可手动点击分析。人工补充的已知手牌单列，不修改冻结起手，也不自动扣除已消耗的牌。输入改变、离开页面或本局失效后旧结果清除，迟到响应不会填回。

1.42.2 将默认阅读顺序调整为「手牌分工 → 关键配合 → 基本展开与注意事项」。顶部显示手坑、护航、解场和启动线索，并逐张解释上手资源；卡文识别的启动线索与经过方案条件核对的一卡动分别表述。副本总数按实际手牌计算，多用途不会增加实体资源。

完成分析后，主卡组选牌区收进「调整起手」；点击已有槽位或展开选牌区仍可修改。构筑统计、卡组关键卡说明、效果参与依据、通用资料和覆盖缺口集中在「资料与依据」，实战页默认收起。通用资料优先列本次手牌，构筑中的其他通用卡继续在下一级展开；情报站的通用维护入口默认打开，原有选择、备注与保存流程保留。

结果只说明所列资源与来源条件，不保证突破未知对手场面，不给出实战交坑时点，不操作游戏。含随机结果的路线直接标注该原因，避免全部显示成含义不明的“待核对”。

## 关键卡资料补充（1.42.2）

新增 `opening-kewl-tune.json`，收录杀手级调整曲与配套共 14 张关键卡的卡文快照、官方来源、核对日期和条件化用途。运行时只在当前卡文与类型匹配时提供对应说明，卡文变化会停用旧用途并保留待核对提示。资料在本机读取，没有在线模型请求。

- [提示员](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=21956&ope=2&request_locale=ja)提供通常召唤入口，可从手牌、卡组或墓地拉出另一只调整；与[自然蔷薇鞭](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=8102&ope=2&request_locale=ja)同时在手时，说明蔷薇鞭仍可从手牌被调用，留作限制点或作素材需作取舍。
- 本家在场并满足相应同调手续时，手牌中的调整手坑可以参与素材；提示会说明这同时消耗原本保留的干扰。
- 检索、增加召唤机会、同调中继、墓地续接、终场无效、保护和攻击推进分别说明；只有本构筑实际存在且卡文吻合的卡片才参与展示。
- “只特召调整”与同调超车的额外召唤限制按具体条件提示，不因为卡在手里就认定效果已生效。卡文参考说明可能的作用，不替代当前禁限表或完整路线验证。

公开参考与录制样本保持分开：补充 14 张卡的说明不会增加方案统计组数。资料来源及更详细的核对范围见[1.42.2 记录](verification-1.42.2.md)。

## 来源与判断

- 主卡加额外副本参与浓度；已知数字系列父子关系归组，独立系列共享成员均分。默认第二系列达到首项 80% 且占总构筑至少 15% 时双主；三个系列同时接近则待核对。用途 TAG 不参与，也不改写原 TAG 选择。内置「同调」（`set:17`）与「融合」（`set:46`）作为通用检索／支援标签单列，不再稀释本家浓度或直接形成独立小轴；具体子系列和用户其他 TAG 保留原规则。情报站可调整阈值。
- 从本地正式方案整理约 8 组、最多 10 组代表路线，按起手入口分散选取，保留少样本和未覆盖说明。复制名称或展示布局不增加票数；规则、条件、区域顺序、终场及卡文版本进入去重依据。
- 起手费用、主卡／额外副本与逐步区域条件复用现有检查。一卡动还用最小指定起手再次检查隐性资源，避免把额外手牌费用省略。受阻分支前提不自动当作本局已成立。
- 从冻结事件重建动作，分别显示发动、处理完成、有实际结果与被无效次数；素材、费用、对象等参与单列。只有至少 3 组样本且有实际作用证据，才按覆盖推荐主要效果；差不超过 10 个百分点并列。能识别为卡片发动的记录单列，例如发动场地魔法不冒充某个编号效果；其他不明确的效果身份、持续适用及旧卡文保持待核对。
- 终场只比较有来源标记的效果清单与项数；同一具体效果多个副本合并列出来源。无效状态单列；共享次数、费用、下回合有效性与斩杀没有完整依据时不生成保证值。相同效果清单不是完整终场等价的证明。

公开效果沿用常用卡资料，并补充[墓穴的指名者](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=13619&ope=2&request_locale=ja)和[抹杀之指名者](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=14627&ope=2&request_locale=ja)的护航条件（2026-09-23 核对）。G／锁鸟、吸引者、结界波的条件提示依据见[讨论稿规则例子](going-second-discussion.md#34-已核对的规则例子与分析含义)。持有不等于效果已生效，收录不表示当前环境允许投入。

## 维护与保存

情报站选择构筑后，可调整已核对通用效果的用途选择、展示顺序、主要／次要优先级和备注。局部路线、主要效果推导仅能备注，备注不参与计算。卡文、身份、费用、局部角色、验证状态等字段由服务端拒绝改写。

「本地归纳候选」从随应用提供的已核对资料生成候选，使用与人工相同的字段格式和校验；生成不覆盖人工选择，点击采纳才应用。卡文或效果依据变化后旧覆盖保留为过期资料，不能继续应用；方案来源变化使旧局部备注显示待核对。没有在线模型调用，也不上传构筑、备注或对局。

个人设置位于运行目录 `_trainer/opening-analysis-v1.json`，每次写入前备份到 `_trainer/backups/opening-analysis/<revision>.json`，修订号冲突拒绝覆盖。缺损文件明确报错，保存失败保留当前输入与旧文件。卡库、TAG、方案和对局源文件独立保留。
