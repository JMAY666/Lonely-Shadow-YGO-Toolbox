# 后攻起手分析

1.42.1 新增独立的本地起手资源分析。入口为「决斗 → BO1 → 手动选择 → 卡组 → 后手」及自动识别的后攻冻结起手；资料维护入口为「情报站 → 起手分析」。

## 使用

手动选择完整起手后点击「分析后攻起手」。自动识别仍沿用已有客户端开局适配：确认后攻并冻结完整起手后，智能识别进入同一分析页；逐步识别可手动点击分析。人工补充的已知手牌单列，不修改冻结起手，也不自动扣除已消耗的牌。输入改变、离开页面或本局失效后旧结果清除，迟到响应不会填回。

分析依次展示手坑、自身影响与冲突、护航、解场、基本展开与补点候选、取胜方向及相对废件。副本总数按实际手牌计算，多用途不会增加实体资源。结果只说明所列资源与来源条件，不保证突破未知对手场面，不给出实战交坑时点，不操作游戏。

## 来源与判断

- 主卡加额外副本参与浓度；已知数字系列父子关系归组，独立系列共享成员均分。默认第二系列达到首项 80% 且占总构筑至少 15% 时双主；三个系列同时接近则待核对。用途 TAG 不参与，也不改写原 TAG 选择。情报站可调整阈值。
- 从本地正式方案整理约 8 组、最多 10 组代表路线，按起手入口分散选取，保留少样本和未覆盖说明。复制名称或展示布局不增加票数；规则、条件、区域顺序、终场及卡文版本进入去重依据。
- 起手费用、主卡／额外副本与逐步区域条件复用现有检查。一卡动还用最小指定起手再次检查隐性资源，避免把额外手牌费用省略。受阻分支前提不自动当作本局已成立。
- 从冻结事件重建动作，分别显示发动、处理完成、有实际结果与被无效次数；素材、费用、对象等参与单列。只有至少 3 组样本且有实际作用证据，才按覆盖推荐主要效果；差不超过 10 个百分点并列。不明确的效果身份、持续适用及旧卡文保持待核对。
- 终场只比较有来源标记的效果清单与项数；同一具体效果多个副本合并列出来源。无效状态单列；共享次数、费用、下回合有效性与斩杀没有完整依据时不生成保证值。相同效果清单不是完整终场等价的证明。

公开效果沿用常用卡资料，并补充[墓穴的指名者](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=13619&ope=2&request_locale=ja)和[抹杀之指名者](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=14627&ope=2&request_locale=ja)的护航条件（2026-09-23 核对）。G／锁鸟、吸引者、结界波的条件提示依据见[讨论稿规则例子](going-second-discussion.md#34-已核对的规则例子与分析含义)。持有不等于效果已生效，收录不表示当前环境允许投入。

## 维护与保存

情报站选择构筑后，可调整已核对通用效果的用途选择、展示顺序、主要／次要优先级和备注。局部路线、主要效果推导仅能备注，备注不参与计算。卡文、身份、费用、局部角色、验证状态等字段由服务端拒绝改写。

「本地归纳候选」从随应用提供的已核对资料生成候选，使用与人工相同的字段格式和校验；生成不覆盖人工选择，点击采纳才应用。卡文或效果依据变化后旧覆盖保留为过期资料，不能继续应用；方案来源变化使旧局部备注显示待核对。没有在线模型调用，也不上传构筑、备注或对局。

个人设置位于运行目录 `_trainer/opening-analysis-v1.json`，每次写入前备份到 `_trainer/backups/opening-analysis/<revision>.json`，修订号冲突拒绝覆盖。缺损文件明确报错，保存失败保留当前输入与旧文件。卡库、TAG、方案和对局源文件独立保留。
