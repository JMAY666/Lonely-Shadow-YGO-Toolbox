# 1.18.1 偏好与搜索修复记录

日期：2026-09-16。本次基于已提交的超先行补丁与全局设置功能集成修复，保留该功能。

## 修复原因

1. 1.18.0 会把达到搜索预算时的部分候选缓存为最终答案；偏好切换与重新生成都可能直接复用，界面也未显示搜索尚未完成。
2. 终场展示虽然只列标记卡牌，搜索仍要求来源中未标记的整片场面，遗漏了实际已经满足标记的目标。
3. 空响应窗口、来源之间的检查顺序、站位变体和重复来源，会影响候选覆盖与预算消耗。

现在偏好参与候选缓存键，仅完整搜索结果允许复用；手动生成强制重算。相同规则校验可复用，但不占用本轮新增校验预算。临时搜索按标记目标匹配，保留额外目标与 IF 条件。只有唯一合法选择为空响应时才补入自动确认；费用、材料、目标和可选效果仍须合法匹配。

相同操作满足多组标记时只算一条路线。只有一条已验证路线，或同一路线同时占优时，多种偏好可能推荐相同路线；搜索受限时不作“唯一解”结论。原路线卡住时展示所需卡片区域，不把牌在手里当成仍能从牌组调出。
