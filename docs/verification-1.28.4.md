## 验收

验收使用后台 Electron 与隔离测试数据，截图来自应用自身渲染器，不操作用户窗口或全局输入。覆盖多个窗口宽高、长短步骤切换、双效果与五张展示手牌、步骤导航、记录依据展开、侧栏切换和分隔线。

- `npm test`：374 项 Python、206 项 JavaScript 测试通过。
- `npm run test:desktop -- --duel-only` 与 `npm run test:desktop -- --automatic-workspace-only`：手动、自动教程验收通过，覆盖尺寸适配、原有导航、分支、快捷键和源记录保留。
- `npm run test:packaged -- --automatic-workspace-only`：发布包自动教程及上述尺寸检查通过。
- `npm run test:packaged -- --duel-only`：发布包手动教程的尺寸适配、原有导航、详情、分支、快捷键及生命周期检查通过。
- `npm run build:dir`：生成 1.28.4 程序包；EXE 品牌检查通过，包内 `duel.js`、`duel.css` 与源码 SHA-256 一致。

尺寸检查覆盖 1440 × 970、960 × 900、900 × 650、1440 × 650 以及回到大窗口；断言所有步骤按钮、当前卡图、文字与箭头均在各自可见区域内。原有拖动、键盘调节及双击恢复流程继续验证。

程序包、截图和验收数据仅保存在本地忽略目录。个人牌组、对局记录、设置、旧包与正式证据保留；本次清理的测试资源均按清单及 SHA-256 核对，并排除仍在运行的测试实例。
