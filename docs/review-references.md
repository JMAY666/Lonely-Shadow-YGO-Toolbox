## MD 图标核对边界

实施时检索了 [MD 官网](https://www.konami.com/yugioh/masterduel/us/en/)及 KONAMI 客服资料。检索结果中的[官方客服条目](https://ja-support1.konami.com/hc/ja/articles/51295577497113)（2026-01-29 更新）说明了信息面板里通常／特殊召唤可否标识，但没有提供覆盖全部日志区域、召唤方式和素材图标的版本化图例；页面进一步访问失败，未据此制作图形复刻。

因此本版使用自己的文字标识：我方蓝色、对方红色，主卡组与 `EX 额外卡组` 分开，攻击／守备／里侧、召唤方式、费用及素材数量各自表达。通常、特殊、融合、同调、超量、连接、仪式和灵摆名称来自已记录的召唤类型。没有核实的 MD 官方图标不作为素材加入项目。

卡图与卡片文本复用已有卡牌资源。新页面没有从参考图裁切第三方图标，也不下载额外商业游戏素材。用户参考图片保留在原路径，不纳入 Git 或应用包。
