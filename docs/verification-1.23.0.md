# 1.23.0 验收记录

新增自动初始起手捕捉、卡牌预览与显式确认，衔接先后攻监测。

## 真实 YGOPro 验收

用户选择两轮先攻和一轮后攻，游戏输入全部由用户完成；工具箱使用只读进程接口、后台 Electron 及独立本地测试目录。

- 先攻第 1 轮：第 0 回合完整捕捉 5 张，包括两张同名卡；逐张预览、详情数据、起手确认与进入下一阶段通过。
- 先攻第 2 轮：完整捕捉另一套随机 5 张起手；新局次和快照 ID 与第一轮不同，确认及落盘回读一致。
- 后攻第 3 轮：第 0 回合捕捉 5 张并提供留存预览；没有先攻确认或方案入口。第 2 回合实际手牌变为 6 张，包含新抽卡，而初始快照仍为原 5 张。
- 卡图曾沿用共享详情组件的小缩略图尺寸，已修正图片及内层容器，使其按比例填满预览框；后攻真实画面及先攻桌面测试画面均已复核，图片和点击框的宽高差小于 2 px。

原始卡牌、进程信息、局次 JSON 和截图只保留在 `.local/ygopro-opening-live-*`，不纳入 Git。

## 范围

起手由初始发牌消息与我方手牌区共同确认，重复卡逐张保留；只在完整匹配后冻结。晚连接、遗漏发牌、长时间中断不能把当前手牌伪装成初始起手。先攻确认进入下一阶段说明页，自动方案匹配仍待接入；后攻仅留存起手，后攻展开未实现。
