# 后攻实战辅助（1.43.0）

本版本把第二至第五点接入同一工作区：解释对方已公开的操作与路线参考、对照当前资源列出威胁、核对响应选择，并在我方回合提供有限场景的短段续接。首版使用 OCG 资料，全部分析在本地完成。

## 进入和使用

在「决斗 → 后攻 → 准备起手」录入完整起手，点击「进入实战辅助 · OCG」。手动模式与 YGOPro 自动模式共用判断与记录。自动模式需要已经确认本局后攻及完整冻结起手；其他客户端的开局功能继续保留，但不进入本版 YGOPro 局面观察。

1. **核对当前资源**。原始起手保持不变，当前手牌、场面、墓地、除外、LP、阶段、已用通常召唤及效果次数另记。勾选对应核对项后保存，缺失项不会被自动当作零。
2. **观察对方**。已记录的公开动作及 YGOPro 新观察到的公开卡参与本地资料匹配。默认最多三条候选，不反推完整构筑、主 TAG 浓度或隐藏手牌。
3. **核对响应窗口**。选择当前连锁最上方的已记录发动，或实际加手／允许快速效果的窗口。确认的是当前游戏事实；查看建议不扣资源。不能跨过更高的待处理连锁去响应下面的效果。
4. **记录实际发生的动作**。选择实体卡、效果编号及实际费用，再分别记录成功处理、发动被无效、效果被无效或未取得结果。真实资源变化通过自动观察或资源表核对，未确认的检索不会变成虚构手牌。
5. **我方回合继续**。使用当前剩余资源、次数与限制，查看短段思路、已保存方案参考和可核对的同调组合。对方响应后重新核对实际状态，已执行事实与原始起手保留。

界面默认显示当前建议、剩余关键资源、对方意图和前三项相关威胁。费用、备选、详细资料、当前资源编辑及历史记录按需展开。可以选择稳健突破、争取取胜或保留续航，并指定想保留的手牌副本；这些偏好不改写规则。

## YGOPro 自动观察的范围

继续使用现有已核对构建：Windows x64 YGOPro 1.036.2，可执行文件 SHA-256 为 `55dd3e8ea4e9a0f24bb2b038e4c95f6e266140469be3480924ff1e57dda1e629`。每次读取重新核对进程身份与模块基址，验证区域边界、卡片控制者、区域、表示标记，以及读取前后的数据一致性。游戏重启、回合倒退、先后攻不符或局次连接失效时不继续采用旧结果。

可读取我方当前手牌与额外、双方公开场地／墓地／表侧除外、区域数量、LP、回合归属，以及已知卡的当前等级和调整身份。自己盖放卡片的身份可保留；对方未公开手牌、盖卡与里侧除外不读牌号，双方牌库不读卡序，对方额外只读数量。

自动模式默认每秒观察一次。相同快照不增加状态修订或重复写记录；局面改变后更新物理资源并撤销旧建议。新出现的公开卡只记为“观察到”，不将快照差异推断成已经完整捕获召唤、费用或连锁。编辑资源表期间暂停观察，避免覆盖输入；读取失败时暂停并显示原因。

**尚不能自动证明完整事件连续性、阶段和响应窗口、已用效果次数及全部持续限制。** 这些项目需要人工确认。快照一致不证明中间没有发生过动作；重新读取场面也不能恢复漏读的次数历史。

人工确认窗口最多保留 15 秒，到期撤销可执行提示；这个时限不表示游戏窗口一定持续 15 秒。游戏中窗口提前关闭或连锁改变时，应立即更新。当前不宣称能自动捕获每一个实战响应窗口。

## 本地判断和已覆盖资料

`live-duel-rules.json` 收录 27 张卡、39 项效果表示，用于明确区分响应条件、费用、次数、限制与威胁；逐卡保留本地卡文快照、类型、等级和官方来源。当前卡文、类型或卡库等级不匹配时停用对应规则，不把旧资料继续当作已核对条件。

当前响应过滤覆盖灰流丽、效果遮蒙者、无限泡影、屋敷童、增殖的 G、小丑与锁鸟、次元吸引者。核对范围包括紧邻效果、手牌发动条件、送墓费用、当前阶段、共享／同名次数、已知取对象保护、同原本卡名无效及已适用的卡组加手限制。其他卡仍可记录实际动作、查看已有公开资料；没有覆盖不等于不可使用。

威胁区分持续限制、无效、保护、移除、续航和攻击推进。判断结合当前魔陷资源、已持有的处理候选与保护关系；一张处理牌不能重复当作多份独立资源。显示的是有前提的策略顺序，不是胜率或完整最优解。公开 OCG 对策用于候选解释，历史月份及文字路线不自动升级为本局已验证的展开。

## 我方回合的限定续接

首版提供提示员、混音手、唱片师、本家检索魔法及结界波的短段参考，并读取现有正式方案，显示当前手牌与原方案条件的对应。已有区域变化、次数消耗或持续限制时，不能把原方案当作回到空场重新执行。

另外覆盖音轨制作人、再混音手、红印鉴唱片师、响度战争四个目标的**两素材同调组合**。要求核对素材当前等级、调整身份、所在区域及本局限制；使用手牌素材时，必须有已覆盖的场上本家卡提供相应手续，且最多取一只手牌调整。保留偏好中的副本不会被推荐用作素材。更多素材、其他召唤手续或复杂替代条件仍需另外核对。

点击「记录游戏中已完成的这次同调」仅记录用户确认的实际结果，更新对应实体素材和额外怪兽，不向游戏发送输入。召唤被无效或去向不同，应直接核对实际局面；不能按成功模板记录。素材和出场触发不自动发动，也不会重置通常召唤或已经用过的效果。

规则核对中特别区分了两类限制：

- 提示员的手牌调整素材手续不属于效果，即使该卡效果被无效仍可适用。提示员①的调整限制从未被无效的处理后开始；此前特召过非调整不因此禁止发动。见[官方 Q&A](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=21956&ope=4&request_locale=ja)。
- 场地③与本家同调魔法的调整限制也按处理结果核对；同调超车的额外限制从发动时开始，发动被无效后才恢复。分别见[场地](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=21962&ope=4&request_locale=ja)、[本家同调魔法](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=21961&ope=4&request_locale=ja)、[同调超车](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=16256&ope=4&request_locale=ja)。

战斗部分目前只计算已确认可直接攻击、攻击力和剩余攻击次数下的条件伤害上限；未知响应、未覆盖效果和攻击限制仍可能改变结果。已记录结界波伤害归零时不安排伤害斩杀，见[官方 Q&A](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=14742&ope=4&request_locale=ja)。

这些短段是卡文、当前事实与来源方案下的条件参考，**没有把真实对局完整复原到引擎**，也不是任意场面的通用解场搜索。

## 保存与校验

每局保存在个人运行目录 `_trainer/live-assistance/<会话 ID>.json`，包含冻结起手、当前资源、实际事件、人工来源和偏好。不会写回个人卡组、TAG、已有正式方案或第一点的通用覆盖。

修改绑定会话与状态修订号；重复请求不重复扣资源，迟到响应不恢复旧页面。保存失败保留原文件和输入。退出辅助后停止观察并关闭对应会话，记录保留；应用重启不恢复活动响应窗口，读取历史状态需重新核对。

资料版本改变也会撤销旧窗口并要求重新核对，原始事实继续保留。已覆盖手坑的自身费用不能漏记；选择分支或目标区域尚不明确时显示条件待核对，不用未覆盖资料作确定的否定结论。

规则环境选择为 OCG，不代表已经读取或逐项验证房间禁限表、特殊房规及全部卡池差异。用户的构筑不会被自动删改。

实现入口：`live_duel.py`、`live_duel_state.py`、`live_duel_analysis.py`、`live_synchro.py`、`ygopro_live.py`。计划沿革见[完善计划](going-second-live-plan.md)，实测范围与未覆盖项见[1.43.0 验收记录](verification-1.43.0.md)。
