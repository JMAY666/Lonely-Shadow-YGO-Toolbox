# 随机牌、效果说明与定向选卡修复 1.26.1

## 修复范围

- 卡组顶部翻牌的具体身份随本局顺序变化。回看按实例显示随机牌卡背，随后除外、放回卡组及一图流沿用该身份；其他同名副本不受影响，原始记录仍保留真实卡名。除外哪张牌仍是效果中的选择。
- 简略与详细日志直接展示已确认的效果原文；发动项未能确定时显示完整卡片原文并注明待核对。一图流附带已确认效果的摘要。按本地公开卡文和对应 Lua 脚本核对提示员、混音手、音轨制作人、旋钮手、唱片师及点唱机酒吧的编号映射，卡文哈希变化后不沿用旧映射。
- 选卡后还要选择选项、召唤区域、表示形式的操作，沿同一核心效果继续对应实际移动。不同效果、再次选卡、响应缺失和实例歧义均保留待核对。来源证据不足与真实随机依赖分别显示。
- 旧方案展示和普通匹配在内存中重算生成的摘要，保留人工补充条件、原文件和批注。新报告使用 `report-v13.json`，不覆盖旧投影与原始记录。
