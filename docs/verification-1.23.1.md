# 1.23.1 临时方案与续接修复

日期：2026-09-17。

## 修复内容

- 方案选择页的生成操作建立从起手开始的新推演，关闭旧推演并清除对应临时教程；普通浏览返回仍保留教程与确认进度。教程内重算沿用已确认前缀。保留来源选择、偏好、精确设置和目标。
- 方案选择页隐藏已有进度的续接面板，生成面板说明计算起点。零候选时说明没有找到可用路线；来源检查统一使用路线检查文字。
- 标准连接召唤的三个 Lua 回调整体移动行号时，允许同卡牌、同召唤类型、同效果属性的素材窗口匹配。卡牌发动效果的函数位置与分支仍严格比较；同一效果属性下不能适配的脚本行号变化显示具体原因并保留未验证状态。实际动作继续通过规则引擎校验。
- 派生索引版本更新，正式方案、历史、个人卡组和原始记录不改写。
