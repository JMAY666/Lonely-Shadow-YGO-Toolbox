# 指定攻击顺序的条件化验证（1.33.0）

内置后攻工作区可以从真实已同步的主要阶段 1 或战斗操作点，在隔离规则核心中验证玩家指定的攻击顺序。攻击资格、对象、次数、伤害和胜负通知均来自核心处理，不按攻击力总和估算。结果只属于明示假设下的演练，不是实际出牌或必胜承诺。

## 使用流程

1. 按[两阶段流程](bo1-second-flow.md)关联同一内置后攻主线练习。在原练习完成解场、展开或实际响应后，同步已结算的我方操作点。
2. 展开“指定攻击顺序的条件化验证”，选择当前我方怪兽，以及直接攻击或对手当前已公开的表侧怪兽。可添加 1–12 次攻击尝试；重复选择同一怪兽仍须核心允许。
3. 点击“隔离验证指定顺序”。固定假设是双方不追加其他可选效果或响应。未覆盖的强制选择、未知目标、随机结果或新揭示的隐藏依赖会停止演练，保留此前完整验证的部分。
4. 查看已验证次数、LP 前后值、停止原因和可展开的攻击顺序／核心事件／前提。伤害、回复、LP 费用分别记录，不把伤害事件自行归类为战斗或效果伤害。
5. 玩家自行在原练习操作。进入战斗或实际攻击后，再同步当前节点；原始起手、已执行历史和旧演练保留，旧结果显示为历史／过期节点。已用攻击次数由完整重放恢复。

主要阶段 1 的[来源路线搜索](bo1-second-routes.md)与此入口分开：先在真实练习操作并同步场面，再验证攻击。主要阶段 2 可以同步回看，当前不能从该阶段继续展开搜索或重新进入本回合已结束的战斗。

## 结果能证明什么

| 显示 | 含义 |
| --- | --- |
| 指定攻击顺序验证通过 | 核心完成所指定顺序；不等于获胜，也不比较其他顺序 |
| 条件分支中核心确认我方获胜 | 在当前规则与不追加可选响应的假设下，核心记录我方获胜且对手 LP 已耗尽 |
| 指定顺序未完整通过 | 次数、资格、对象、未覆盖选择、隐藏信息或预算等阻止完成；不表示规则上无解 |
| 历史／过期节点 | 实际节点、观察、规则或局次已改变；只供回看 |

不能仅凭 LP 为 0 宣称获胜；还须相符的核心胜负通知。核心内部可能在过量伤害后暂存负 LP：界面最低显示 0，`core_lp_after` 与逐步事件保留原始值。对手手中即使存在可响应卡，本次“不响应”分支也不能证明它不会使用；隐藏卡身份不进入结果或策略依据。

只支持有完整日志且引擎、卡库、脚本一致的内置练习。MD 和其他外部平台的完整规则状态、卡池及禁限表均未认证。每次最多 12 项、96 个决策，约 22 秒的逐决策预算（单次原生调用可能延后返回）；每局最多保留 40 次演练。未穷举、来源不足与超时均不能解释为无解。

## 已验证的原生反例

| 场景 | 核心结果及验证边界 |
| --- | --- |
| 无公开阻挡，1500 攻击对手 1000 LP | 不追加响应的分支出现核心胜负通知；对手隐藏消战者身份不输出，未宣称能穿过其响应 |
| 攻击 1200 守备的表侧怪兽 | 1500 攻击通过核心处理，此次无贯穿伤害，对手 1000 LP 保留 |
| 光子斩击者与另一只 1500 怪兽 | 卡面攻击力共 3600，对手 3000 LP；另一怪兽仍在场，核心拒绝光子斩击者攻击，仅造成 1500 伤害 |
| 同一普通怪兽攻击两次 | 第一次完成，第二次不在合法菜单；实际完成一次攻击并同步后，也不返还次数 |
| 对手里侧怪兽身份未知 | 提交前拒绝以隐藏身份预测战斗，不生成确定伤害结果 |

另有单元检查：LP 耗尽但无胜负通知、攻击目标不一致、隐藏卡揭示、盖卡洗切、冲突胜负通知和迟到结果均不能变成确定结论。它们是契约检查，不冒充额外原生卡组案例。

光子斩击者的攻击限制见[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=9882&ope=2)。测试使用敌人操纵器改变公开怪兽表示，其对象和时点见[官方 FAQ](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=5505&ope=4&request_locale=ja)。消战者可响应直接攻击并结束战斗阶段，见[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=8617&ope=2&request_locale=ja)；本次只验证明确放弃该响应的分支，没有覆盖其实际发动。

## 视频案例补核：假面变换

官方简中名为“假面变换”，本地库使用“假面变化”，测试绑定卡号 **21143940**。速攻魔法的发动以我方“英雄”怪兽为对象；将其送墓是效果处理，不是发动费用。特殊召唤的前提关注对象是否因本效果离场，且不是融合召唤；本卡文无同名每回合一次条款。依据为[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=9066&ope=2&request_locale=cn)，不能把“对象丢失等同于无效”作为规则。

固定原生核心验证以下三种处理，均未出现发动无效或效果无效消息：

- 正常处理：影雾女郎被本效果送墓，特殊召唤暗属性假面英雄。
- 连锁给死者的供物先破坏对象：对象提前离场，假面变换不再特殊召唤；这是处理条件不成立，不是无效。
- 次元裂缝适用：对象因假面变换的处理离场并改为除外，仍特殊召唤对应假面英雄。不能把“未到墓地”一律当作失败。

给死者的供物的破坏对象见[官方 FAQ](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=5214&ope=4&request_locale=ja)，次元裂缝的送墓替代见[官方卡文](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6707&ope=2&request_locale=cn)。以上是已列明组合的本地核心结果，未认证 MD，也没有新增泛化的 HERO 交康推荐。测试选用已知卡号的假面英雄，不据此猜测转录中“暗爪大人”等未核实名称。

## 数据与兼容

`battle_history` 单独保存观察版本、来源节点、指定顺序、条件与核心事件。演练不追加原练习输入，不改当前资源、观察版本、起手、正式方案或已有提示。规则／来源变化时重新校验；关闭、换局或重启后拒绝旧权限和迟到结果。

原普通展开报告继续隐藏没有效果的战斗流程步骤，原始攻击与伤害事件仍保留；新面板不把纯战斗噪声加回原教程。详细命令、实际结果与发布范围见[1.33.0 验证记录](verification-1.33.0.md)。
