# 1.20.0 自动选择前端流程

本次按「先完成前端，下一步接入真实功能」实现。手动选择进入原有卡组流程；自动选择经过 YGOPro（初代原版）平台、卡组识别和卡牌预览。新增内容沿用现有颜色、方形插画、步骤条、卡牌详情与标记方式。

## 实现与数据边界

- 识别页左侧显示主／额外／副卡组缩略图，右侧提供获取和下一步；获取前不能越过识别步骤。
- 预览页复用手动卡牌详情和按副本标记，增加名称、示例 AI TAG、搜索、主副 TAG 切换和移除。
- 保存处理空名、禁用字符、Windows 保留名及同名冲突。取消覆盖保留原演示记录，确认覆盖同时替换演示卡牌和 TAG。同名实际卡组只用于展示冲突，不修改其文件。
- 演示草稿保留在当前决斗会话中，切换页面或模块后仍可继续。手动卡组和自动草稿独立；开始新一场、刷新或关闭窗口后清空演示数据。
- 「开始决斗」只提示后续接入状态，不请求引擎，也不进入自动起手或教程。示例卡牌文字、图片来自已有本地卡库，没有新增识别、AI 或持久化接口；Python 仅补充新页面资源的静态路由。
- 保存面板在窄窗口内独立滚动，底部留出浮动按钮的位置。原生窗口、规则引擎、记录格式和正常训练起手随机逻辑未改动。
