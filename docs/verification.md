## Electron 桌面与嵌入式场地

当前桌面版由 Electron 主进程启动固定版本的嵌入式 Python 服务，并用独立用户数据目录启动工作副本引擎。YGOPro 在创建时使用 Electron 主窗口作为 Win32 父窗口，保留原生场地控件和规则处理，场地位于“训练场地”页面内。后台仍为独立原生进程，由本次服务的 Windows Job Object 管理。

按用户要求，后续验收改为后台实例：通过引擎自己的命中检测、Irrlicht 事件及渲染截图完成操作，不移动系统鼠标、不发送全局按键。验收实例使用固定种子并在原始日志标记 `test_control: true`，正常训练继续使用随机种子，内部测试接口默认关闭。
