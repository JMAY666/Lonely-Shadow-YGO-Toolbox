# 情报站

情报站位于左侧「全局设置」正上方。首版是本地个人知识管理工具，不读取实时对局、不自动出牌，也不提供账号、点赞或社区发布。断点布局参考用户提供的操作顺序图，其中具体搭配没有作为规则依据导入。

1.38.2 使用双栏工作区：顶部分类显示资料总数，新增和汇总操作位于右侧；左栏放置分类、带标签的筛选项和资料列表，右栏显示当前资料。进入页面或切换分类时打开首条资料，点击列表中的资料名称切换编辑，点击卡图仍可预览卡牌。筛选不会丢弃正在编辑的内容；列表只高亮当前可见的已选资料。桌面窗口中编辑内容独立滚动，保存、取消和移除操作位于底部；较窄的网页窗口使用上下布局。

「添加卡牌」与「汇总方案标记」临时使用完整工作区，关闭或完成选择后返回编辑。未保存修改仍沿用放弃确认、保存失败保留输入和版本冲突核对流程。

卡名／卡号和 TAG 筛选常驻左栏；类型、属性、种族与等级筛选位于「卡牌筛选」折叠区，选中条件的数量会显示在折叠标题中。折叠不取消条件，「清空筛选」会同时重置搜索、TAG、卡牌条件和文件夹／主题选择。

## 终场标记

在「终场标记」添加卡牌，填写候选标记、通用用途和各项效果备注。卡牌通用用途和每个效果都可以「添加备注」，多条备注并列展示，可单独编辑、移除。相同内容去重，来源信息附在备注下方；手动改写后标为手动标注，原始来源快照仍可查看。可以组合使用 TAG、卡名／卡号、类型、属性、种族、等级／阶级／LINK 筛选，一键清空恢复全部资料。

展开回看终场时，点击卡牌，浮层会重新读取该卡的通用标注与并列备注。「一键应用到本方案」把候选标记、效果选择和用途复制到当前实例；之后可以独立调整或取消。默认保存范围为「仅用于本方案」；选择「同时合并到通用标注」并确认后，向通用库补入本方案的新说明，保留已有不同备注；方案内修改仍须按原有确认流程保存方案。

应用到方案时，并列备注以空行分隔写入原有备注字段，不改变方案格式；多条备注不增加效果数量。如果合计超过方案原有单处 4000 字上限，会明确提示先精简，原通用备注保持完整，不截断保存。

通用库不描述卡牌在任意场面中必定有效，也不会自动增加路线评分或阻抗次数。通用标注修改或删除不会改写已保存方案、分支和原始对局记录。卡库效果文本与通用标注的快照不一致时，禁止直接应用；采用当前文本时把原选中效果及其备注转入「旧文本效果 · 待核对」，可逐条核对并归入当前效果。

「汇总方案标记」汇总已保存方案的主线与已记录分支。可以点击「合并此卡全部标注」或「全部合并到通用库」，也可以展开来源后仅合并其中一份。同一卡号统一一份资料，兼容的效果选择取并集；相同备注合为一条并保留多个来源，不同备注并列，不覆盖已有手写说明。批量合并是一次原子保存，来源过期或写入失败时整批不提交。

对应效果以完整效果文本核对，文本相同但位置变化时可以重新对应；文本不同或无法唯一对应时，保留效果原文、备注和来源并标为待核对，不按同一个数字序号强行合并。待核对部分不会自动应用到方案，用户可手动归入当前效果。来源方案修订后再次合并会保留新旧说明及来源快照；相同来源版本只合并一次，不会反复恢复用户已移除的备注或推翻手动归入结果。并列备注表示来自不同条件或方案的说明，不宣称它们在同一局面中全部有效。

## 手坑标记

「手坑标记」从完整卡库选择由用户确认有手牌干扰用途的卡牌。主卡组怪兽、魔法和陷阱都可选择；额外卡组专用类型和衍生物不可添加。这里没有预设一张牌必定是手坑，也不按效果自动加入。

1.38.3 在资料编辑中增加「关注的效果」：逐条勾选卡面文本，为已选效果填写备注，也可「添加备注」并列保留不同条件，分别编辑或移除。点击「保存资料」后，效果选择和备注与用途说明、使用条件、文件夹一起保存；取消勾选并保存会移除该效果的标记及备注。列表显示已标记效果数与效果备注数。手坑效果备注与通用终场标注独立，不自动写入方案或断点记录。

效果依据保存时的卡面文本展示。卡库文本变化时会提示核对；「采用当前文本，保留旧备注待核对」将旧效果原文与备注保留在待核对区域，可逐条归入当前效果。缺卡时继续保留已保存文本，仍可编辑备注。

手坑成员和唯一的「手坑」用途 TAG 使用同一份成员资料。TAG 管理也可以添加或移除成员，并使用同一类型校验；保留其他 TAG。此用途 TAG 与系列分类区分，不参与卡组／方案的主副系列自动识别。

文件夹是单层整理视图，提供「全部手坑」「未分组」。在资料编辑中选择其他文件夹并保存即可移动；删除文件夹会把成员转到未分组，保留效果选择及备注。TAG 管理保存仍保留成员时，也保留这些资料。移除手坑标记会同时移除对应 TAG 归属、手坑效果标记、备注和文件夹归属，通用终场标注和其他 TAG 保留。历史断点中的卡牌引用继续保留。

## 解场标记与常用分类

1.39.0 增加独立的「解场标记」资料库。解场资料有自己的单层文件夹、用途、条件、逐效果备注及「解场」用途 TAG，可以收录主卡组与额外卡组卡牌，衍生物不可添加。与手坑重复的卡可以在两处分别维护，例如无限泡影的手坑用途和后攻解场用途。删除其中一类的资料不会删除另一类；TAG 管理对「解场」成员的修改与此资料库同步。桌面资料列表独立滚动，分类与筛选保持可见。

在「手坑标记」或「解场标记」点击「导入常用分类」，确认后原子合并内置的 2026-09-20 资料。手坑包含 10 类、28 张，解场包含 8 类、39 张，合计 64 张不同卡牌。文件夹按主要效果分组，额外的「效果 · …」用途 TAG 可交叉筛选；用途 TAG 不参加系列自动识别。

导入保留已有非空用途、条件和文件夹，补充独立效果备注。原资料为空时才采用资料库提供的整卡用途和条件。原有「无效」文件夹可复用为卡组与特召效果无效分类。每份资料可展开「参考资料」查看核对日期、原始整理说明和官方链接；手动改写某条备注后，该条仍标为手动标注。

相同版本重复导入不重复追加；后来手动移除的效果或备注不会被该版本自动恢复。删除整份资料后再次导入可重新建立该份资料。卡库缺失的卡会跳过并列出卡号，卡面文本无法准确对应的效果进入待核对区域。不同文本不按数字序号强行对应。来源、分类表和维护命令见[常用卡资料](staple-catalog.md)。

## 断点管理

### 主流卡组图解与资料导入（1.40.0）

1.41.0 将主题导航分为两级：上方「OCG」「Master Duel」大主题显示所属卡组主题数量；点击后，下方「卡组主题」只列该环境的子主题，显示名称省去重复前缀。点击「全部」时按 OCG、Master Duel、个人与跨环境主题分组；「个人主题」保留无研究来源的记录与空主题入口。同一主题若包含两个环境的资料，在两边均可筛选，全部列表中只显示一次。

切换大主题会清空旧的子主题选择，保留搜索与 TAG 条件。当前没有未保存修改时，会在需要时打开筛选后的首条资料；有未保存修改时保留右侧草稿。记录编辑中的主题选项也按环境分组，仍可移动到其他主题。分类来自记录的环境信息，不仅凭名称猜测，不改写主题编号、名称、引用或个人文件；已有资料无需重新导入。

点击「导入主流对策」将内置的 2026-09-20 资料写入主题与断点库。OCG 与 Master Duel 分开，共 20 份：8 份 OCG、12 份 MD；58 个断点与 97 个配卡图的路线节点。来源覆盖 7—9 月的赛事证据与 9 月 20 日榜单，各条显示实际采样期，不能将发布日期当作比赛日期或把社区上位分值当作天梯使用率。完整收录范围见[主流对策资料](matchup-catalog.md)。

导入资料默认阅读模式；旧个人资料仍默认编辑。图解先列前提，再按有序卡图解释操作和资源变化，可跳到对应断点。放行、此处阻抗、仍有补点并列展示。断点里的应对选项按实际场面选择，不要求把一条资料内的手坑依次交完。卡图来自本地卡号对应的卡牌资源，点击继续查看原卡文；不是录像截图。

列表可按全部、OCG、Master Duel、个人资料筛选，并组合主题、搜索与 TAG。搜索包括标题、概要、步骤说明和图解所用卡名／卡号；图解独有卡也参加 TAG 筛选。桌面版的来源链接在系统浏览器打开；网页使用新标签页。全部引用区分环境证据、对策参考与官方卡文；长来源默认折叠。

「编辑资料」可以改概要、识别线索、优先打断、误区、样本说明和原有步骤。来源版本、日期与原始图解保留为导入快照，手动保存修改后标记「已个人编辑」。改动步骤时立即停用原图解到步骤的跳转及旧的逐步引用，保存后仍保持此状态；原始图解与总来源仍可查看。

导入不会覆盖旧个人记录或同版已编辑条目。主题重名时为新导入主题添加资料版后缀，不妨碍原主题继续编辑。缺卡仍保存核实的稳定卡号，显示卡库缺失，不猜测替代卡。一次导入原子保存并备份，同版无变化时不增加修订号。若其他入口删除了当前正在修改的导入记录，冲突核对后可另存个人记录，原概要、图解及来源完整保留为折叠的个人参考副本，不冒充当前步骤的已核实来源。

图解和条件分支是人工核对卡文后的推演，未逐局进行规则引擎回放，不代表最优策略或实战胜率。

### 手动维护

先建立主题，可关联已有卡组、一个或多个 TAG，也可以只填自定义主题名称。一个主题可包含多条记录。存在记录的主题不能直接删除，需要先移动记录到其他主题或删除记录。

每条记录按步骤显示对手卡牌、具体操作／效果、干扰时点、条件和备注。每个步骤的应对选项放在该步骤下面，默认为互相可选的单独方式；同一选项需要多张卡时必须改为「组合 · 多张卡配合」。也可以只填写文字应对方式。手坑库提供快捷选卡，切换到完整卡库可选择任意应对卡；这不会改变手坑成员。

可新增、删除或上下移动步骤，分别维护各个应对选项的条件、预期作用和备注。引用使用稳定卡号，名称和图片仅供展示。支持按主题、TAG、标题和涉及卡牌搜索。缺少对手卡牌、操作、时点、条件或应对资料时显示「待补充」；填写完整也只显示「待核对」，始终明确是用户策略资料，尚未经规则引擎验证。

## 对手卡组（1.41.0）

第四个分类「对手卡组」是独立的只读公开资料页，原断点管理继续保留。通过 OCG／Master Duel、来源统计期、TAG、卡名／卡号或构筑名称筛选。列表按来源统计期倒序，同期按牌型样本占比降序；每个统计期保留实际分母及其收录口径，不跨期拼成一个占有率。

右侧查看构筑的主卡、额外和副卡图解，每种卡显示实际张数。OCG来源未披露副卡时明确显示缺失；MD按客户端标准构筑展示主卡与额外。点击卡图仍能查看卡牌详情，来源链接在桌面版由系统浏览器打开。TAG沿用现有系列编号；主TAG按来源牌型核对，附加TAG的匹配卡号保留在结构化数据中，不创建或修改个人TAG成员。

构筑下方至少有两条基础展开路线，包含所需起手、其他素材／费用要求、逐步操作与结果、关键终场和保留资源。路线引用的物理卡必须属于该构筑主卡或额外，起手与终场张数不能超过所收录数量。路线是当前卡文条件推演，不是规则引擎执行记录，也不宣称对应选手实际采用了这些步骤。

资料内置于 `src/trainer/opponents.json`，经 `GET /api/intelligence/opponents` 读取。页面没有构筑编辑或保存控件，POST请求会拒绝；不会写入个人卡组、TAG文件或方案。旧断点、手坑、解场与通用标注继续使用原管理流程。详细覆盖、来源与稳定引用格式见[对手卡组资料](opponent-catalog.md)。

## 存储、兼容与恢复

- 数据保存在当前用户运行目录的 `runtime/_trainer/tag-library.json`，复用其中的 `entries` 和新增的 `intelligence` 字段。未建立第二套卡牌或 TAG 身份库。开发与验收数据在仓库的 `.local/`，打包应用的个人运行目录沿用既有桌面配置。
- 通用终场标注、手坑资料、单层文件夹、主题和断点记录采用版本 1 格式；每次写入与用途 TAG 成员同步原子提交。所有管理入口共用 TAG 文件修订号，过期写入会被拒绝，前端输入保留。
- 原有 TAG 文件无需预先改写；首次保存情报站资料时增加字段。已有正名为「手坑」的 TAG 复用原编号；旧成员资料保留，新增和再次保存成员时必须通过主卡组校验。以后其他标签不能再创建同名专用 TAG。正常已有方案没有批量迁移。
- 1.38.1 将旧的单条通用备注读取为一条并列备注，纯读取不改写文件；实际保存前继续备份旧文件。通用标注使用 `notes` 保存独立条目及来源，保留派生的 `note` 文本供旧格式读取；旧方案的原有字段不迁移。
- 1.38.3 为手坑资料补充 `desc` 效果文本快照、`effects` 与 `unmatched_effects`；每个效果的独立备注沿用 `notes` 和派生 `note`，整卡用途仍使用原有 `note`。旧手坑资料读取时补充空效果选择，纯读取不写文件；保存前继续备份旧版。通过 TAG 新增的成员也可直接编辑效果。
- 每次覆盖前把旧文件写入 `_trainer/backups/tags/<修订号>.json`。恢复时先退出本应用，另存当前 `tag-library.json`，选择所需修订备份复制回原位置，再启动应用。恢复范围是该版本的 TAG 与情报站全部资料，方案文件和记录不会随之回退。不要在服务运行中手工替换。
- 卡库暂时缺卡时显示缺失提示，保留卡号、备注、已保存效果文本和断点引用。只允许新增当前卡库中的卡牌，已有缺失引用仍可编辑备注或移除。
- 保存失败保留输入并显示失败原因；遇到其他入口已更新的冲突，可以读取新版并保留输入，查看新版内容、明确核对后再决定是否保存覆盖。切换模块也保留未保存编辑，退出时沿用未保存提醒。个人文件、备份、验收截图和安装包都留在本地忽略目录，不进入源码提交。

本次验证使用合成方案和真实卡库资料测试管理与复用行为，不验证示例卡牌之间的规则合法性或战略收益。
