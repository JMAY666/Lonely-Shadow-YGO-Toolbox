## 持续监听修订

按新增需求，将一次智能识别改为持续的进程订阅：本局结束自动关闭本局上下文、释放计算并等待下一场；下一场不需要再次点击识别。每局独立周期、局次和输入，旧周期响应与 TAG 线程不能回填。短暂读取变化重试，丢失连续性只放弃本局并等待下一场；通过退出状态和创建身份识别客户端关闭。新增跨局、后攻转先攻、读取恢复和旧 TAG 线程测试；重试请求绑定当前周期和局次，下一局的连接失败也会正确收回旧界面。完整桌面基线之后，本次修订重新通过全量单元测试，并执行开发／打包智能识别专项。
