# YGOPro 阶段、回合玩家与素材（1.35.0）

在[公开资源核对](bo1-second-live.md)的同一入口补充三类信息：可见阶段、已观察的回合玩家、怪兽承载的素材。继续使用“先读取预览 → 核对 → 再次读取并采用”，保留原始起手和旧观察历史。

## 当前能力

| 信息 | 读取依据 | 缺失时的处理 |
| --- | --- | --- |
| 阶段 | 已核实客户端的阶段控件文字，支持抽卡、准备、主要 1、战斗、主要 2、结束 | 控件不可见或文字未知时保留待核对；控件身份或边界错误则拒绝本次读取 |
| 回合玩家 | 连续采样见到回合计数加一，并同时读到对应的新回合消息；按既有我方视角转换玩家 | 晚接入、错过消息、计数跳号／倒退、换场景或中断超过 2 秒时保持未知，不按奇偶猜测 |
| 素材数量与归属 | 怪兽素材列表、素材区域／序号及对承载怪兽的回指同时一致 | 归属不一致、重复对象或变化中途拒绝本次快照；未知素材身份不补猜 |

同一回合中缓存重复出现的新回合消息不能改变已记录玩家；实际观察到同一玩家连续行动时也不强制交替。读到玩家或阶段不表示当前允许响应，战斗阶段文字也不等于伤害步骤。

素材以本次承载关系关联到当前卡片实例。采用后，素材卡片显示承载怪兽名称；旧记录仍保留当时的关系。对手里侧承载怪兽下的素材身份保守隐藏，即使缓存里可能留有卡号；取除、转移或离场的原因不从两次快照差异推断。没有实际卡号时只显示未知素材和数量。

客户端标记禁止查看墓地时，暂停整份资源详情读取，不使用缓存中的卡号绕过该限制。标记地址经固定源码与对应二进制写入路径核对；特殊限制的更多真人交互仍需另行验收。

## 核对与失效

- 采用当前快照会导入其中已读取的阶段／回合玩家；没有依据的项目继续手工核对。
- 人工核对不能覆盖已读取的相反结果。客户端进入下一阶段时，应重新读取，而不是把旧快照手工改成新阶段。
- 阶段、回合玩家或素材变化也会使旧局面标记失效。确认采用前再次读取并比较，迟到或不同版本的结果不覆盖当前记录。
- 既有已使用的共享次数不会因同步返还。素材归属不是稳定的跨动作实例证明，卡片用途和实例次数仍需核对。

当前只支持此前已核实的 YGOPro 镜像，资源布局标识升级为 v2。其他客户端及旧历史快照不会自动获得新字段。原正式方案、先攻流程、内置规则核心、原始日志和个人数据保留。

## 仍未完成

完整事件流、连锁、合法响应窗口、指示物、具体费用和无效结果、次数与持续限制尚未接入。单槽消息缓存会覆盖中间消息，不能据此宣布事件齐全或重建规则状态。当前外部局面仍不能直接用于内置后攻路线或战斗验证，也未认证 MD 卡池与禁限表。
