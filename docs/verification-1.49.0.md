# 1.49.0 标注驱动用途库与起手角色验收

日期：2026-09-25。此版本按用户授权，直接重建旧的用途资料和分析角色，允许替换已标注卡片原有的个人用途、条件、效果备注及角色覆盖；不再只增加参考区。

## 变更范围

- 启动时备份并重建终场、手坑、解场资料。当前 498 张标注生成 91／35／174 张用途记录，覆盖范围以实际安装卡库为准。
- 常用资料仅提供已有的用途分类依据，具体效果、条件、次数、备注、来源版本改为读取统一标注。整卡用途不会自动挂到不相关的场上续航效果上；特殊召唤手续和从手卡放置发动的陷阱保留原有已核对用途依据。
- 起手的角色统计与效果说明直接读取统一标注；旧的对应个人覆盖先备份，再停止使用。用途 TAG 成员同步重建。
- 已管理卡片显示统一效果编辑入口，移除重复的旧用途／条件／效果备注编辑器与旧导入入口。旧客户端再次写入的冲突内容会在同步时被规范资料替换。
- 原方案的录制事件、具体实例、实际局面和历史标注快照不改写；未标注卡片的旧记录仍作为待补充资料，不从资料缺失推断没有能力。

本次不修改原生引擎算法，未重跑全套原生展开场景。

## 本机资料升级

对当前安装目录使用维护工具，在服务锁保护下实际执行升级，并验证原文件备份。具体的前后数量、revision 和备份位置仅记录在 `.local/reviews/annotation-knowledge-20260925/` 的本地迁移回执，不提交用户资料。维护工具使用不启动会话恢复的最小服务集合，避免附带修改对局记录。

分类中的“标注推导”表示静态用途线索。共享次数、分支、费用和当前局面仍需核对，分类数量不等于当前可用干扰次数。
