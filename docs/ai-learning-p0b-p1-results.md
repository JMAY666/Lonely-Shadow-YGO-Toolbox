## 范围与版本

本机 Windows、CPython 3.13.13、PyTorch `2.12.0+rocm7.14.1`、RX 9070 XT；继续使用原隔离环境，未重新安装框架或修改显卡驱动。控制器继续使用原模型试验的独立 Python。付费 API、云 GPU 和本轮 LLM 调用均为 0。

## 端到端成本

下表使用相同的 30 个新起手初始窗口，双方均为新会话历史，并通过独立进程通信。计时从已读取状态的特征构造到策略返回，包含编码及 IPC，排除实际引擎提交/结算；不同模型仍使用各自的特征结构。

| 策略 | 状态到策略返回 p50 | p95 | 最大值 |
| --- | ---: | ---: | ---: |
| 新学生 CPU 2 线程 | 5.67 ms | 6.79 ms | 76.39 ms |
| 新学生 CPU 4 线程 | 4.69 ms | 6.45 ms | 60.66 ms |
| 原 TFLite CPU 2 线程 | 4.23 ms | 4.92 ms | 5.11 ms |

新学生在共同窗口的纯模型中位数为 2 线程 2.40 ms、4 线程 1.88 ms。每个起手依次设置 2/4 线程，没有排除线程切换及系统调度造成的尾延迟，最大值保留；这是小规模部署选择依据，不是正式 1,000 窗口性能验收。默认继续使用常驻的 4 线程学生。

50 回合的分项结果：

| 环节 | p50 | p95 |
| --- | ---: | ---: |
| 读取当前状态 | 1.03 ms | 1.41 ms |
| 玩家观察及特征构造 | 2.11 ms | 2.82 ms |
| 原生动态查询和记录 | 2.98 ms | 3.89 ms |
| 928 次学生网络推理 | 2.35 ms | 2.98 ms |
| 所选响应的副本重放校验 | 60.11 ms | 86.94 ms |
| 实际提交至后继引擎窗口 | 146.27 ms | 2,102.92 ms |
| 回合最终完整前缀重放 | 74.22 ms | 102.85 ms |
| 一个开发回合，含循环停止 | 16.09 秒 | 32.44 秒 |

50 回合工作进程总耗时约 **14.42 分钟**，含进程加载、资源检查、采样、执行和记录，排除外层 Electron 初次启动。新学生新进程启动约 2.38 秒，旧模型约 0.27 秒；两者在批次内常驻。正常用户使用的动画/隐藏渲染仍在，不能称为已经完成无渲染核心批处理。模型前向已经较快，进一步提高 GPU 推理速度不能消除引擎、渲染、通信和重放的开销。

双实例在各自的服务、缓存、会话与运行目录下同时运行，并从原生起止时间确认了重叠。5 个固定简单案例：单实例约 28.44 秒；双实例合计 10 个案例约 30.38 秒，短测吞吐约 **1.87 倍**。这不是 50 个复杂相剑回合的并行成绩。首次第二环境解压造成无实际对局重叠的运行单独保留，没有用它证明并行加速。

## 资源与下一批门槛

50 回合中已知隔离进程的采样工作集峰值约 **0.99 GiB**，低于 8 GiB 批次限制；这是合计采样工作集，不是单独学生进程的独占内存或系统级强制限额。开发结束时学习目录约 **9.51 GiB**；双实例环境和全部证据保留后，提交前检查约 **10.75 GiB**。GPU 本轮未另采样驱动级峰值，不沿用旧 101 万参数探针的显存数值。

当前未压缩证据平均每个回合约 **15.87 MiB**，p95 约 27.68 MiB。按全部 50 个结果计算：

| 新家族数 | 按实测批次平均耗时 | 每家族两次尝试、按 p95 的规划值 | 未压缩证据，平均 / p95 |
| --- | ---: | ---: | ---: |
| 200 | 约 0.96 小时 | 约 3.60 小时 | 3.10 / 5.41 GiB |
| 2,000 | 约 9.61 小时 | 约 36.04 小时 | 30.99 / 54.06 GiB |

两次尝试是明确的保守规划假设，不是测出的重试概率。存储列按每家族一次记录；若保留两次尝试，证据量还需加倍，200 家族的高位存储估计也可能超过当前剩余空间。**这些数字尚未计入 T0 搜索或 LLM 教师成本**，不能据此承诺完整实验耗时。274 个已关闭的原生会话累计存活约 24.01 分钟，包含失败和调试等待，并行按进程相加；该数不包含所有应用启动和外部控制时间。

结论是进入 **200 家族小试的协议与教师标定准备**，先固定划分，再用训练部分的 20 个家族测真实教师成本和有效数据率。小试完整成本必须仍在 4 小时内；若不满足，先降低经过登记的搜索预算或优化运行器。当前不能直接启动 2,000 家族：保守时间超过 24 小时，原始证据也超过整个学习目录的 20 GiB 上限。需先验证证据压缩/状态引用去重和批量执行成本，保留原始失败记录，不靠删除失败或放宽预算宣布可行。
