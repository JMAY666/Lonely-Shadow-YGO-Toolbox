## 边界

- 当前可标注 14,716 张，参考样本 11 张，未标注 14,705 张。未标注不等于无能力。
- 官方来源是静态知识依据，脚本映射不是整卡规则验收；没有接入实时发动判断。
- 自动草稿仍是关键词候选，不能直接确认为完整标注；完整结构通过资料文件维护。
- 效果层组合查询不证明互斥分支能同时执行。
- 测试使用独立数据目录与隐藏 Electron 窗口，不操作用户窗口或发送系统输入。原个人数据、旧版本和备份保留。
