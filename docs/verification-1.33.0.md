- `npm test`：435 项 Python、218 项 JavaScript 全部通过。
- `npm run test:modular -- --suite=second-rules` 与 `npm run test:modular:packaged -- --suite=second-rules`：各 3 个假面变换案例、5 个战斗场景和桌面界面通过。原生场景包括正常处理／对象提前破坏／送墓替代，条件直攻获胜、守备目标无贯穿、光子斩击者限制、重复攻击与实际次数续接、隐藏目标拒绝。

- `npm run test:modular -- --suite=second-flow`：两阶段、实际交灰后抽牌、无响应与不同对象上的连续泡影回归通过，已执行前缀和旧窗口复盘保留。
- `npm run test:desktop -- --second-only` 与 `npm run test:packaged -- --second-only`：未关联原生的人工流程、五张手牌案例、历史恢复、原先攻入口、三种手坑的条件比较和关联处理结果回归通过。

## 保留边界

只验证指定顺序、当前公开目标与双方不追加可选响应的分支。强制选择、隐藏依赖、预算耗尽时停止，不声明无法斩杀。消战者夹具只验证其不响应分支，没有验证实际发动；伤害减免、反射、多次攻击等更多效果组合仍需独立验收。

所有桌面与引擎检查使用后台 Electron、隔离测试数据和内部接口，无系统鼠标或全局按键输入。未重复全部既有原生专项，未进行外部真人 MD／YGOPro 对局验收。规则与来源详见[指定攻击顺序说明](bo1-second-battle.md)。
