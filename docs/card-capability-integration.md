# 跨模块卡片能力与自动用途库 · 1.49.0

卡片标注通过 `CardCapabilities` 提供效果投影，`AnnotationKnowledge` 自动重建终场／手坑／解场用途库和起手角色。1.49.0 按用户授权直接替换已标注卡片原来的独立用途、条件、备注及角色覆盖，并在写入前保存原文件备份。当前资料仍只覆盖已标注范围；未标注不等于没有能力。

## 使用入口

| 入口 | 行为 |
| --- | --- |
| 卡组编辑 | 卡牌详情增加可展开的能力摘要，显示效果、条件、费用、对象、次数和处理分支；卡牌库可按效果能力筛选。 |
| 通用卡片浮层 | TAG、断点、教程、回看等使用的公共浮层显示相同能力资料，可定位到完整标注与具体效果。 |
| 终场／手坑／解场标记 | 以统一标注生成的用途及对应效果为主体，显示条件、费用、次数和处理。原来重复维护的编辑器改为“编辑统一标注”；“重新同步标注”可重建分类。 |
| 三类用途分类 | 随有效标注自动更新成员及效果引用；手坑保持主卡组限制。已核对的旧用途目录只作为分类依据，不再提供另一套效果事实。未覆盖的卡可用“补充未标注卡”整理，自动草稿不会取代这些资料。 |
| TAG 管理 | 自定义 TAG 支持能力搜索；手坑／解场专用 TAG 自动共用用途库成员，禁止在另一处单独改写，且不参与系列识别。 |
| 起手分析 | 原有手坑／解场／护航／资源角色、统计和通用效果说明直接读取统一标注；旧的对应角色覆盖备份后移除，构筑及路线局部备注仍保留。 |
| 断点管理 | 相关卡片的当前能力资料按需展开，供核对策略中的条件；不会把手动断点转成规则验证结果。 |
| 实战辅助 | 已知卡片可查看统一能力资料；合法性和当前响应窗口继续使用已有状态与规则判断，静态标注不扩充客户端读取范围。 |
| 模块化与临时方案 | 终场增加保存时的能力构成及条件说明，只统计用户选择的实例和效果；既有路线计分与引擎验收不被静态标签替代。 |

## 数据边界

- 引用身份是整数卡号、效果键和卡文指纹，不按卡名、标签名或旧效果序号强行对应。
- 只有当前卡文匹配、来源不是自动草稿、状态为已核对／已确认／部分标注的已标注分段，才参与能力筛选和用途候选。部分标注仍明确显示其状态。
- 草稿、待核对资料可供阅读，但不提供采纳候选；卡文过期、历史卡文不匹配或缺卡时不把当前效果挂到旧文本上。
- 用途候选从具体处理、发动区域与时点形成，页面明确显示“候选”。个人增加一个标签不会凭空证明该用途；自我破坏不会被直接认定为处理对方卡牌。
- 多个筛选条件须命中同一效果。共享次数、互斥选择和处理分支保留展示，多标签、多分支和多条备注均不累计为可用阻抗次数。
- 已标注卡片的旧用途、目录和效果备注由规范资料重建。常用卡的已有用途身份与标注推导分开显示；不会将整卡的手坑身份挂到不相关的场上后续效果上。具体方案的目标仍按实际实例选择。
- 同步只改写用途库及对应的旧起手角色覆盖，写入前通过原子保存机制备份。未标注卡片的旧资料仍作为待补充内容保留。旧客户端改写已管理资料后，下次同步会恢复为统一标注生成的内容。

## 更新与历史

`POST /api/capabilities` 支持单卡 `op: card` 和最多 120 张的批量 `cards: [{code, text?}]`；可提供显示中的卡文，服务先核对指纹。`GET /api/capabilities` 返回筛选词表。`/api/cards` 的 `effect_tag`、`purpose_candidate` 与既有卡片条件取交集。

首次启动自动执行升级；后续标注变化会更新用途资料及 TAG。用途库备份位于 `<runtime>/_trainer/backups/tags/<revision>.json`，旧起手覆盖备份位于 `backups/opening-analysis/<revision>.json`。同步幂等，读取相同版本不重复写入。写盘失败保留原文件，可修复磁盘问题后重试。

离线维护可用 `python scripts/rebuild_annotation_knowledge.py --runtime <运行目录>` 只读预览，追加 `--apply` 应用；工具拒绝同时占用该目录的运行服务，不触发历史会话恢复。恢复旧版本时先退出程序，保留新版文件后从对应备份恢复旧文件；再次启动 1.49.0 会重新生成规范资料。

投影内容版本包含实际效果、个人修正与显示词表。每次读取从标注服务取资料，标注写入和卡库重载沿用既有缓存失效机制；页面保存标注后通知引用区域刷新，重新打开模块也会刷新。起手分析的来源版本包括相关能力版本，更新后旧的分析保存请求需要重新核对。

新保存的本地方案在 `annotation_snapshot` 中冻结当时的能力投影及版本，包含分支；后续浏览和修改公共标注不回写历史方案。旧方案没有快照时明确显示缺失，保留原卡文、人工标记与录制证据，不自动补造历史核对结果。临时终场引用其来源保存的能力，不将相似标签视为可替换路线。

能力快照中的全局个人备注保留本地，方案分享继续只包含原有的方案说明；导出时移除能力快照及模块化来源中附带的能力投影，避免无意带出其他个人备注。导入的旧格式分享依旧可用，缺少能力快照时显示未知。
