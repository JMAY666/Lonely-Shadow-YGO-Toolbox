## 真实客户端对局

| 场景 | 实际观察 |
| --- | --- |
| 正式路线 | 通常召唤成功后完成第一步；效果发动、选卡／格位／表示形式期间保持执行中，特殊召唤和连锁完成后才完成第二步 |
| 无效与偏离 | 主动加入无效响应后停止，保留前两步；无效处理后显示不能按成功推进，重新同步仍不跳过第三步 |
| 临时路线 | 第二轮随机起手没有既有匹配路线。在隔离工具箱中用真实原生引擎录制短来源并生成临时候选；未修改原九份正式方案。先在 MDPRO3 操作再采用候选，自动定位到已经完成的步骤 |
| 同名副本 | 一张同名卡从手牌到指定怪兽格，另一张仍在手牌；实例、位置与操作记录对应 |
| 临时记录 | 四条内部决策合并为一个教程步骤，实际确认范围 0–3；`temporary_confirmed=4`，界面完成一步，只有一次 `live_confirmed_step` 审计且来源为 `mdpro3-read-only` |
| 人工浏览与重同步 | 实际完成不因回看撤销；返回实时进度重新对齐，重新同步不重复确认 |
| 生命周期 | 记录到对局结束、旧工作区退出、进程关闭与重新捕捉到新进程。新进程主菜单不复用旧教程；同一订阅完整进入下一真实局仍未追加验证，由自动化覆盖新 Start 与局次更替 |

当前代码重放两轮真实保留证据，分别恢复正式路线两步并阻止偏离、恢复临时路线一步完成；重复处理不重复确认。此项不计为新增真实对局。

尚未真实验证快速连续多步、复杂超量素材流程、所有对手干扰和长路线；这些目前只有合成测试或既有原生记录的编译核对。带续接前缀的临时候选、无法证明结果的效果和不支持消息继续显示待确认。
